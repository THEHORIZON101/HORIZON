# GPT-5.6 Operating Kit

This folder is a complete operating system for using GPT-5.6 well across coding, research, writing, presentations, learning, data, games, visual work, and business.

## Start here

1. Read the complete [`GPT-5.6 tested operating manuscript`](manuscript/GPT-5.6-COMPLETE-MANUSCRIPT.md).
2. Apply [`settings/CHATGPT-SETUP.md`](settings/CHATGPT-SETUP.md).
3. Paste [`settings/CUSTOM-INSTRUCTIONS.txt`](settings/CUSTOM-INSTRUCTIONS.txt) into ChatGPT Personalization.
4. Use [`profiles/SUBJECT-MATRIX.md`](profiles/SUBJECT-MATRIX.md) to choose the model, reasoning level, tone, skills, and custom GPT for a task.
5. Copy the matching specialist instructions from [`custom-gpts/`](custom-gpts/).
6. Use [`benchmarks/README.md`](benchmarks/README.md) to understand the empirical results and rerun the executable benchmark.

## What is included

- A recognized OpenAI HumanEval-derived executable sample benchmark.
- The prior 95/100 single-session capability audit, with its limitations preserved.
- A complete ChatGPT personalization recommendation.
- Model and reasoning guidance for Sol, Terra, and Luna.
- Subject-by-subject skill stacks.
- Copy-ready instructions for ten Naano custom GPTs.
- Two reusable skill blueprints that fill real gaps instead of duplicating existing skills.
- A compact prompt library and quality checklist.

## Evidence standard

The HumanEval result is reported as **5/5 on a public five-task sample**, not as a full HumanEval score. It was produced in one Sol High session and is vulnerable to benchmark contamination because HumanEval is public and widely known. Treat it as executable evidence of basic coding correctness, not a leaderboard claim.
