# Recommended ChatGPT setup

## Personalization

| Setting | Recommendation | Reason |
|---|---|---|
| Base style and tone | **Candid** | Direct, honest, actionable, and encouraging; best match for decisive guidance without filler |
| Warmth | Slightly below default | Keeps the conversation human without burying the answer |
| Enthusiasm | Low | Prevents generic praise and exaggerated claims |
| Headers and lists | Medium | Enough structure for technical work without over-formatting |
| Emojis | Minimal/off | Better for school, coding, documents, and serious creation |
| Custom Instructions | On | Carries stable response and collaboration preferences across chats |
| Reference saved memories | On | Preserves durable preferences and goals |
| Reference chat history | On | Helps continuity; use Temporary Chat for sensitive or one-off work |

OpenAI describes Candid as direct and encouraging, with clear risks, gaps, trade-offs, and next steps. Personality changes communication style, not capability. Task-specific prompts can and should override tone when the artifact needs something else.

## Model and power defaults

- **Everyday work:** GPT-5.6 Terra, Medium.
- **Important schoolwork, analysis, or ordinary coding:** GPT-5.6 Sol, Medium.
- **Hard coding, architecture, research, books, polished presentations, and complex builds:** GPT-5.6 Sol, High or Extra High.
- **Clear extraction, classification, transformation, and bulk summaries:** GPT-5.6 Luna, Low or Medium.
- **Max:** reserve for the hardest single problem where quality matters far more than speed or credits.
- **Ultra:** use only when the task divides into genuinely independent workstreams; most tasks do not need it.

The official default Power setting uses Sol with Medium reasoning. Use the lowest reasoning level that passes your actual quality test.

## Memory and Projects

- Keep global memory for durable preferences: learning style, tone, devices, long-term goals, and recurring constraints.
- Create separate Projects for Books, Coding, School, Business, and Games.
- Use project-only memory when a project should not borrow assumptions from unrelated chats.
- Store project rules in project instructions or files, not in an enormous global Custom Instructions block.
- Use Temporary Chat for sensitive tasks or when you want no memory influence.

## Apps and plugins

Connect only apps you trust and actually use. Recommended:

- GitHub for repositories, issues, pull requests, and publishing.
- Google Drive when school or writing files live there.
- Canva for branded social designs and Canva-native presentation work.
- Sites for hosted websites and interactive tools.

Apps may receive relevant conversation or memory context when invoked. Review permissions and disconnect apps you no longer need.

## Best global behavior

Global instructions should control collaboration, not every subject. Subject-specific behavior belongs in the matching Project, custom GPT, or skill.
