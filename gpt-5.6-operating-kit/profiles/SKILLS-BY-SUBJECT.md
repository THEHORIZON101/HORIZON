# Skills by subject

## Coding, websites, and apps

- Lead: Sites for Sites projects; Repo Doctor for broken repositories; standard coding workflow otherwise.
- Support: GitHub for repo context/publishing, Asset Integrator for supplied media.
- Verify: Visual Quality Inspector for UI, performance checks for heavy interfaces.
- New skill needed: none for ordinary software work; the existing stack is already strong.

## Games

- Lead: Browser Game Builder.
- Support: Asset Integrator; Voxel World Art Director for voxel projects.
- Verify: Play-test, Performance Optimizer, Visual Quality Inspector, Repo Doctor.
- Rule: “Builds” and “opens” are not equivalent to “play-tested.”

## Books and narrative writing

- Lead: Write Exceptional Books.
- Support: Humanize Writing for the final natural-voice pass.
- Verify: continuity checks inside the book workflow.
- New skill needed: none unless a recurring genre has special research or continuity rules.

## Presentations

- Lead: Presentations for PowerPoint/Slides artifacts; Canva Branded Presentation when a Canva brand kit is central.
- Support: Answers Images and Answers Charts only when visuals improve comprehension.
- Verify: render and inspect every slide; do not judge quality from slide text alone.

## Research

- Lead: domain-specific official documentation skill when one exists; otherwise web research.
- Support: PDF for papers and reports, Documents for a polished deliverable.
- Verify: claim-level citations, source conflict handling, dates, and inference labels.
- New reusable gap: Benchmark Lab for testing models, prompts, and configurations empirically.

## Studying

- Lead: Adaptive Study Director blueprint included in this kit.
- Support: subject-specific tools such as spreadsheets, charts, or documents only when useful.
- Verify: retrieval practice, teach-back, delayed review, and transfer—not merely a fluent explanation.

## Data and spreadsheets

- Lead: Spreadsheets.
- Support: Answers Charts for a fixed chart; Visualize for user-adjustable exploration.
- Verify: formulas recalculate, totals reconcile, units match, and charts reflect source ranges.

## Documents and PDFs

- Lead: Documents or PDF according to the final format.
- Support: Library for persistence.
- Verify: render every page and inspect clipping, tables, spacing, headings, and missing content.

## Images and visual design

- Lead: Imagegen for raster creation/editing; Canva for Canva-native branded design.
- Verify: Visual Quality Inspector.
- Do not use generated imagery for precise technical diagrams or numeric charts.

## Permanent-skill rule

Create a new skill only when the workflow recurs across projects, contains non-obvious procedure, cannot be covered by an existing skill combination, and saves more context or errors than it introduces.
